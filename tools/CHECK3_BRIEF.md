## A 包：`tools\check3_align\align_NN.txt` —— 判「标题 / 汤面 / 汤底」是否同一故事 + 污染残留

格式（每题 3 行，题间空行）：`[数字id] 《标题》` / `汤面: …` / `汤底: …`，`⏎` 表示换行。

只报这些 kind：
- `mismatch`：汤底完全解释不了汤面，或讲的是另一个毫不相干的故事（必须真的毫不相干才报）。
- `truth_empty`：汤底不是答案（无意义的一句话、图片说明、结果发表、活动公告）。
- `title_wrong`：标题与汤面汤底都无关，或是站内标签/作者吐槽而非题名。
- `truncated`：汤面或汤底在句中突然结束。
- `junk`：夹带与谜题无关的内容（站方公告、投票结果、作者致谢、署名、URL、扫码/关注导流、大段装饰线残留）。
- `unplayable`：玩法上不能当海龟汤玩（要玩家改写题目本身、纯猜物、需看图、需与站方页面交互）。

不许当错误报的：
1. 汤底不与汤面共用措辞是本类谜题的正常写法。
2. 标题短、带引号、带系列前缀正常。
3. 汤底里刻意保留的假名双关、颜文字、`▽解说`/`【答案】`/`简易解说`/`【蛇足】`分层，是原文写法，不算污染。
4. 机翻腔、语句生硬、黑暗猎奇、多解「或者…」式汤底都不算问题。
5. 本题库没有关键词表，不要因「没有关键词提示」报问题。
6. 分隔线若承担结构功能（如待办清单的题面框线 `〜〜〜`、`----`），保留是对的；只有大段刷屏式装饰线才算 junk。

## B 包：`tools\check3_pair\pair_NN.txt` —— 判「日文原文 → 现库中文」有没有译错译漏

格式（每题 5 行）：`[数字id] 《中文标题》 原帖 #id` / `原文汤面:` / `现库汤面:` / `原文汤底:` / `现库汤底:`。
**这一轮的包全文输出、没有任何截断**，所以译文少了下文就是真少了，可以照实报。

只报这 5 类 kind：
- `mistranslate`：意思译错（否定反了、因果颠倒、人物关系错、关键名词张冠李戴、数字/时间/量词错）。
- `omission`：原文属于本题的内容在译文里整句/整段缺失（含汤底首行谜底、末行收尾句）。
- `untranslated`：该译成中文的地方留着整句/整串日文没译（刻意保留并加了中文括注的假名双关不算）。
- `cut`：译文句子在半截处结束，而原文同处还有正文。
- `addition`：译文多出原文没有的情节（措辞润色、为解释双关加的括注不算）。

不要报：BS 公告、作者致谢/署名、`らてクエ`活动说明、评论区、颜文字刷屏、装饰线、站外 URL——这些在译文里被删掉是**正确**的。
固定人名译法（カメオ→龟男、カメコ→龟女、カメミ→龟男美、ウミオ→海男、ウミコ→海女、キョウコ→京子）是站方惯用角色，必须照此统一，不算改动。
短题干被扩写成整段中文（原文一句话、译文两三句）属正常意译补足，只有**新增情节/新人物/新道具**才算 `addition`。

## 输出（两种包通用）
- 写到 `tools\check3_verdicts\<包名>_<编号>.jsonl`（如 `align_01.jsonl`、`pair_03.jsonl`），目录不存在就创建。
- 每个问题一行 JSON：`{"id":"数字id","kind":"…","field":"surface|truth|title|all","note":"≤40字中文证据","quote":"原文或译文摘录≤60字"}`
- 一行一个 JSON，不要数组、注释、markdown 代码块。整批无问题写一行 `{"id":"NONE","kind":"none","field":"all","note":"整批无问题","quote":""}`
- **必须逐条读完整批**（文件大，用 Read 的 offset/limit 分多次读到结尾），不要抽样。
- 结束用一句话汇报：读了多少题、报了多少条、各类多少。
