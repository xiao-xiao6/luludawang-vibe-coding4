# 第六轮 · 裁定简报（对「复核员报出的疑点」逐条裁定是否成立）

项目根目录：`C:\Users\Administrator\AppData\Roaming\@opensquilla\desktop-electron\opensquilla\workspace\海龟汤小游戏`

## 你面对的是什么
`tools\_r6_cards_N.txt` 里是 42 个复核包（A 包判中文三态对应/污染，B 包判日译中译文对原文）报出的 **101 条疑点**，按题切成 4 份。
每一份里每题的结构是：
```
########## #题号 《中文标题》 [批次]
  ▲[来源包] kind.field: 疑点说明
     引: 原文或译文摘录
  ORI_S: 日文原文汤面
  CUR_S: 现库中文汤面
  ORI_T: 日文原文汤底
  CUR_T: 现库中文汤底
```
**这些疑点只是「候选」，其中相当一部分是误报。** 你的任务是当**二审**：对着 `ORI_*` 逐条裁定它成不成立。

## 裁定口径（重要）
1. 只有当**现库中文与日文原文确实不符**（意思相反/人物错置/数字错/该译的整句没译/原文没有却新增了情节），或**确实缺了属于本题的正文**，才 `accept`。
2. 下列情形一律 `reject`：
   - 删掉了站方脚手架：`BS問題`/`BSタイム` 规则块、`【参加テーマ・…】` 活动标签、`らてクエ` 回收说明、`質問欄にてヒント所望`、`※出題期間終了` 期限公告、作者署名/致谢/谢辞/外部 URL/ブログ村。
   - 删掉了**作者在同一帖里写下的其他题/其他天的谜底**（系列题只保留本题部分是对的）。
   - 删掉了大段颜文字/拟声词刷屏演出（`ｶﾞﾀﾝｺﾞﾄﾝ`、`＼(≧∀≦)／` 重复几十行），只要剧情句还在。
   - 为解释双关/专名加的中文括注（`呑む（既指喝酒也指吞食）` 之类），以及因此变长的译文。
   - 刻意保留的假名双关、颜文字、`▽解说`/`【答案】`/`简易解说`/`【蛇足】`/`＜解说的解说＞` 分层。
   - 承担结构功能的分隔线（`〜〜〜` 待办清单框、`----` 分节、`◆◆◆`）。
   - k1 批次（162 道最早题）译文把原文换行压成一整段、没有 `⏎` —— 排版差异，不是漏翻。
   - 原文页面自身前后矛盾（作者自己混用人名/人称/数字），译文照实译出。
   - 短句干被意译扩写、措辞生硬、机翻腔、黑暗猎奇、多解汤底。
   - 标题短、带引号、带系列前缀、题名是歌名/惯用语双关（**除非标题与汤面汤底完全无关且明显是标签或按语**）。
   - 复核员只是「觉得可以更好」但没有客观错误。
3. `unplayable`（玩法上不能当海龟汤玩）只在**中文玩家确实无法进行是/否追问**时才 accept，例如纯猜一个字符、纯填空、要求玩家改写题面；带知识双关但汤底自洽解释了的，reject。
4. 若 accept，必须给出**可直接落地的精确改法**：
   - `field`：`title` / `surface` / `truth`
   - `old`：**逐字照抄现库文本**里要被替换的那一段（含标点，≤60 字，必须在该题该字段里唯一出现）
   - `new`：替换后的中文（同样 ≤60 字，风格与现库一致，不要加解释性按语）
   - 若属于「整行缺失需要补回」：`old` 填要插入位置的那一**整行**（现库里逐字照抄），`new` 填「该行 + ⏎ + 补回的行」，`mode` 写 `line`。
   - 若属于「删除残留」：`new` 可以是空串，`old` 填含前后多余标点的完整片段。
5. 拿不准就 `reject`。**宁可不改，不可改坏。**

## 输出
写到 `tools\check6_judge\judge_N.jsonl`（N 用你负责的份号），一条疑点一行 JSON：
```
{"id":"题号","packet":"来源包","kind":"原报的kind","verdict":"accept|reject",
 "why":"≤40字裁定理由（要引用日文原文关键词作证据）",
 "field":"title|surface|truth","old":"现库逐字片段","new":"改后中文","mode":"sub|line"}
```
- `reject` 的行不用填 field/old/new（留空串）。
- 一题被多个包报了多条疑点时逐条裁定，不要合并。
- 结尾一行：`{"id":"COVERAGE","kind":"meta","field":"all","verdict":"meta","why":"已裁定X条/共Y条","packet":"judge_N","old":"","new":"","mode":""}`
- 只读，不修改任何数据文件（只写你自己的 judge_N.jsonl）。
