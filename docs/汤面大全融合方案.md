## 5. 数据规范（`SOUP_LIBRARY` 每条）

```js
{
  id:        "lib_3f9a1c2e70b4",  // "lib_" + sha1(normalize(surface)) 前 12 位
  srcNo:     312,                  // JSONL 行号（1 起），便于回溯
  title:     "",                   // 原文标题（可为空串）
  dispTitle: "无题 · haiguitang.top #312",  // 显示名，永远非空
  surface:   "...",
  truth:     "",                   // 可空
  mode:      "surface",            // "truth" | "surface"
  cats:      ["悬疑"],             // 库受控词表，≥1，已排序
  rawTags:   ["反转", "短篇"],      // 原始标签，去重后字典序
  difficulty: 2,                   // 1 | 2 | 3
  src:       "haiguitang.top",
  srcUrl:    "",
  lang:      "zh",                 // "zh" | "en"
  quality:   "clean",              // clean | needs-review | no-truth
  _t:        "..."                 // 预计算检索索引 normalize(dispTitle + "\n" + surface)
}
```

**`id` 取舍**：内容哈希而非数组下标。下标方案在 JSONL 增删后整体错位、玩家存档全废；内容哈希天然幂等 + 去重。代价是「改一个错字 → id 变 → 该题进度丢」，对浏览型汤库可接受。

### 5.1 `mode` 三态

| mode | 条件 | 条数 | 玩法 |
|---|---|---:|---|
| `truth` | `truth` 非空 | **681** | AI 汤主正常对战 |
| `surface` | `truth` 为空 | **680** | 五个交互按钮全禁用 + 「这锅只有汤面，汤底还在熬」 |

### 5.2 难度映射（`tools/mapping/difficulty.json`）

`1` ← 简单/easy/1　`2` ← 普通/中等/medium/2/3　`3` ← 困难/hard/4/5/地狱
空值 → `2` + `needs-review`；黑名单 `1-5 (1最容易，5最难)` → 丢原值走默认 + `needs-review`

### 5.3 库受控词表（27 词）

18 个项目受控词（= `smoke_test.js` 的 `CAT_POOL`，一字不改）
+ 8 个库扩展词：犯罪 猎奇 日常 搞笑 亲情 悲剧 逻辑 本格
+ 1 个兜底词：**其他**

> ⚠️ `其他` **只存在于库词表**，绝不能加进 `smoke_test.js` 的 `CAT_POOL`，也不能让 `E.allCats(PUZZLES)` 返回它（顺序一致性断言）。库词表定义在 `library.data.js` 的 `SOUP_LIB_CATS`，独立常量。
> 映射后为空 → `cats=["其他"]` 且 `quality="needs-review"`。实测兜底 867 条，属预期（后续人工/LLM 补标）。

### 5.4 显示名兜底

实测 309/1397 条标题为空串：

```
title 为空 → dispTitle = "无题 · " + srcLabel + " #" + srcNo
否则       → dispTitle = title 折叠空白（顺带修掉 2 条含换行的标题）
```

### ② `smoke_test.js` 的 `defer` 计数断言

施工单 §7.2 说「只允许 2 处改动」，但现场自检里有一条硬编码 `6 个业务脚本全部 defer`（`deferCount === 6`）。加了 `library.data.js` 后必然变 7。

**处理**：把它改成断言**性质**而非个数 —— 「所有 `<script src="js/...">` 都必须带 `defer`，且 `deferCount >= 6`」。这不是放宽，而是去掉一处与文件数耦合的脆弱断言。

### ③ P7 与「100 题」断言直接冲突

`smoke_test.js` 有 `PUZZLES.length === 100` 的硬断言。施工单 P7 要求把首批 20 道从汤库升级进 `PUZZLES` —— 一旦注入，这条断言必挂，而 §7.2 又禁止改动它。

**本轮处理**：只交付**管线与校验工具**（`tools/gen_puzzles_from_library.py` + `tools/check_puzzle_drafts.js`），草稿产出到 `data/library/puzzle_drafts.json` **暂存**，**不注入** `js/data.js`。是否放宽这条断言、以及草稿的人工过闸，请主人决定。

- 35 个来源全为公开爬取，含 `Jed's List`（1999 英文经典）与许二木扫描件 OCR。**已保留 `src` + `srcUrl`**
