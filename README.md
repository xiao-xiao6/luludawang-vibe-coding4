## 什么是海龟汤

「海龟汤」是一种水平思考谜题。出题人给出一个看起来离奇的**汤面**，玩家只能提问，一步步还原背后的**汤底**。

汤主的回答只有四种话：

| 回答 | 含义 |
|:---:|---|
| **是** | 方向对了 |
| **不是** | 方向错了 |
| **部分正确** | 半对半错，复合提问常见（精品关键词汤主只回前三样，第四种随 AI 汤主上线） |
| **与此无关** | 这条线索不在谜题里 |

经典例子：

> **汤面**：男人走进海边的餐厅，点了一碗海龟汤。他只喝了一口，就放下勺子问服务员：「这真的是海龟汤吗？」服务员微笑点头。男人付了钱，回到家中，举枪自尽。为什么？
>
> **汤底**：多年前他遭遇海难，漂流荒岛。同伴把死者的肉煮成汤，骗他那是「海龟汤」。今晚这碗正宗海龟汤味道完全不同，他才明白当年喝下的是什么。

## 怎么玩

1. 从首页「从第一题开始」「随便来一锅」进入，或用顶栏的「随机一题」「随机模式」（按题材 / 火候抽题）「汤库」找题。
2. 读汤面，用是非问句提问。左栏「问答记录」留档本局每一问每一答，可一键清空。
3. 卡住了没有提示可要——**线索 / 提示 / 探索度机制已整体下线，全靠提问熬真相**。想弃锅就点红色的「放弃」，确认后直接上汤底。
4. 想通了点「我要猜汤底」，用自己的话把推理讲清楚。
5. 右栏是**备忘录**：随手记推理、串线索，自动存在本机浏览器，刷新不丢。
6. 嫌关键词太死板，点「AI 汤主」，填上自己的模型 Key。配置只存在本机浏览器里。

| 星级 | 条件（精品层，`par` 为标准提问数，默认 8） |
|:---:|---|
| ★★★ | 提问数不超过 `par` |
| ★★☆ | 提问数不超过 `par + 5` |
| ★☆☆ | 其他情况 |

提示机制下线后，星级只看提问数。存档自动保存，随时「继续上一锅」。

猜汤底是四级判定（`js/engine.js` 的 `judgeGuess`）：

| 级别 | 触发 | 汤主怎么说 |
|:---:|---|---|
| **solved** | 把汤底那层意思原样写出来（汤底回声），或核心词 + 关键词命中达标 | 「对了！你把最关键的那一层说破了」 |
| **close** | 摸到核心词或至少两个关键词 | 「已经很近了——你摸到了关键，但还差最后一层」 |
| **vague** | 话太短，没把谁 / 为什么 / 怎么做串成一句 | 「汤主听见了，但你得把话说完整」 |
| **no** | 方向不对，**或只是把汤面复述了一遍** | 「你只是把汤面又念了一遍」 |

抄谜面不会被判通关：汤面里本来就有的关键词一律清零。

## 多人房间

顶栏「多人房间」建房，或用 6 位房号进房（字符集去掉了易混淆的 `I / O / 0 / 1`）。进房后才要昵称。

- 全员点「我准备好了」且房主已选汤后自动开局；提问顺序随机固定，之后中途加入的人排进当前轮询队尾，不掀桌不打断。
- 每人提问限时 90 秒，「本锅」头部有全桌可见的倒计时；超时自动跳过并在对话流里播一条「XX 超时，已跳过」。没轮到自己时输入框仍可先打字存着，只是不能发送。
- 轮到自己时画面亮一圈，并有一声短铃。
- 猜汤底随时可以。完全跑偏冷却 180 秒，沾点边（部分正确 / 接近）冷却 60 秒，只算在猜的人自己身上，全桌其他人不受影响。
- **猜底全程私密**：你写了什么、汤主判了什么色，只有你自己的屏幕看得到，不进共享问答记录；每人有一份私有的「猜底手账」回看自己猜过的每一条。只有猜对那一刻由汤主在聊天里报喜（只报名次，不报汤底），已说破的人不能再猜。
- 房间最多 15 人。「放弃」是发起全房投票：同意数凑满「人数 − 1」直接揭底，有人明确拒绝到数学上不可能凑满、或 60 秒不达标即流产。
- 房主可以选汤、随机一锅、配 AI 汤主、转让房主，也可以请离任意玩家；离线超过 1 分钟的座位标成「请离死座位」。
- 联机是 1.5 秒一次的 HTTP 增量轮询（不是 WebSocket）：快照带 `rev` 游标，无变化只回 `unchanged`；切后台停轮询、回前台快速补拉；断线重连靠本机固定身份，回来还是同一个人。
- 问答记录看两处：左栏自动慢滚、中区「实时对话」看当下，「问答记录」按钮里是完整清单。AI 判定时全桌可见「汤主正在思考」横幅，不会毫无反馈。
- 四种回答分色：是（绿）/ 不是（红）/ 与此无关（灰）/ 部分正确（黄）。
- 结算和进行中都有战况三小格：个人提问数 / 全桌总提问数 / 从开锅算起的用时。
- 汤库与房间「选一锅汤」的卡片都带题材标签（脑洞 / 悬疑 / 都市 …）；卡片右上角的绿勾是本机「已熬出汤底」标记，点一下切换，熬出汤底时自动打勾，只存在自己浏览器里。
- 界面全部图形为同一套手绘线条 SVG 图标（`js/icons.js`，35 个），不再使用 emoji。

联机服务：https://soup-room.57gqq9hsq.workers.dev

### 数据怎么发布

- 汤底明文随站点发布，防作弊交给玩家自觉（2026-09-23 起单人局也走本地真汤底，让 AI 汤主吃底判定）。多人房的判定仍在服务端，房间快照不下发未揭晓的汤底；`GET /api/truth/:roomCode/:puzzleId` 只在房间已揭底（`phase=revealed`）时才回汤底。
- 母本 `data/library/library.data.js` 与服务端生成题库 `worker/src/*.data.js` **不进仓库**，只在本地和部署时存在；`js/library.public.js` 是它的发布产物，不要手改。
- GitHub Actions 的 `site-guard` 守卫会检查：内部数据源不被跟踪、`js/library.public.js` 可当普通脚本加载且题量 / 带底数不低于 800、汤底污染防回归脚本通过。
- 2026-09-27 做过一次全库体检：1621 道逐条去重、查污染、核翻译，删掉 41 道重复（37 道汤库内重复 + 4 道与精品层撞车），汤库 1521 → 1480；同时修掉约 23 处 OCR 错字、markdown 残留、源站主持人话术、引号不配对，并统一了日译中的人名译法（カメオ→龟男、ウミオ→海男 等）。

## 双端适配

桌面是三列：左栏问答记录、中区汤桌、右栏。右栏在单人局是**备忘录**，进多人房自动换成**房间聊天**（同一块位置由 JS 切换，线索板已下线）。1180px 以下改成单列，问答记录在上，右栏在下。

| 宽度 | 行为 |
|---|---|
| ≥1181px | 三列。1380px 以下两侧栏略收窄。多人房时右栏是竖排块，聊天框固定高度不挤线索区 |
| ≤1180px | 单列。问答记录限高；房间聊天改钉屏幕右下角（fixed） |
| ≤1024px（至 861px） | 平板档：右栏列表区高度再收一档（旧线索板遗留的限高） |
| ≤860px | 按钮热区 ≥44px，输入框 16px（避免 iOS 聚焦时放大整页） |
| ≤420px | 顶栏按钮换行，聊天框收成右下一条 |
| ≤360px | 边距和字号再收一档 |

另外照顾到：

- 刘海、手势条用 `viewport-fit=cover` 和安全区内边距；`100dvh` 适配移动地址栏伸缩。
- 横屏矮视口（≤520px 高）压缩首页和对话区高度。
- 触屏（`hover: none`）去掉悬停位移，避免点完按钮还飘着。
- 软键盘弹出时收起音乐台和已展开的房间聊天，并缩短对话区。
- `prefers-reduced-motion` 关掉动效与转场。

### 手机端省电档（`@media (pointer: coarse)` + `SoupFx` 内 LITE）

针对「120Hz ProMotion 手机上不开特效都发烫、开特效卡」的反馈（iPhone 16 Pro）。根因是所有无限循环动画和 rAF 在 120Hz 下按 120 次/秒计费，而 `text-shadow` / `box-shadow` / `filter` / `background-position` 这几类关键帧没法走 GPU 合成，等于常驻重画整块内容。触屏设备一律：

| 开销 | 桌面 | 手机端 |
|---|---|---|
| 雨幕 Canvas | 60~120fps、dpr≤2、220 丝按透明度 6 分桶批量 stroke | 封顶 30fps、dpr≤1.5、密度 ×0.6、尘埃减半、闪电辉光改廉价双层描边 |
| 蒸汽 / 扫描线 / 全屏 backdrop-filter | 开 | 关（overlay 混合与高斯模糊是 iOS 烧 GPU 大户） |
| 标题辉光 / 徽章呼吸 / 结算炫彩字 / 报喜彩框 / 墨晕 | 无限循环 | 全部停成静态一档 |
| 问答记录自动慢滚 | rAF 每帧写 scrollTop | 节流到约 30fps 才写一次 |
| 庆祝烟花 | 全量粒子 | 粒子减半 |
| 氛围特效开关 | 默认开 | 新访客默认关（存过的偏好不动） |

桌面 `pointer: fine` 完全不受影响；`SoupFx.stats()` 会回显 `lite` 方便真机排查。

## 技术栈

没有前端框架，也没有打包步骤。双击 `index.html` 就能玩单人局。唯一引入的第三方库是本地化的 GSAP（`assets/vendor/gsap.min.js`），只用于转场，缺了也能降级运行。

| 层 | 用了什么 |
|---|---|
| 页面 | 语义化 HTML + 原生 CSS |
| 逻辑 | ES5 风格 IIFE，挂在 `window.SoupXxx` |
| 转场 | GSAP 黑幕三段式（盖黑 → 换内容 → 拉开），降级链 GSAP → Web Animations → CSS → 瞬切 |
| 图标 | 一套 35 个 24×24 手绘线条 SVG（`js/icons.js`），stroke=currentColor，全站零 emoji |
| 图形 | Canvas 2D 雨幕 / 闪电 / 尘埃 / 乌鸦 / 判定火花 / 前景庆祝烟花 |
| 音频 | Web Audio API 实时合成 4 首 BGM + 十余种音效（含轮次提示铃），无音频文件 |
| 字体 | 标题用子集化 `NotoSerifSC-title.woff2` |
| 存储 | `localStorage` |
| 离线 | Service Worker（缓存名 `deepsea-soup-v17`，HTML/CSS/JS 走 network-first、图片字体走 cache-first，仅 https 下注册）+ Web App Manifest |
| 联机 | Cloudflare Workers + Durable Objects（SQLite 持久化），HTTP 1.5s 增量轮询 |

脚本顺序：`gsap.min.js` → `data.js` → `library.public.js` → `engine.js` → `ai.js` → `audio.js` → `fx.js` → `transition.js` → `icons.js` → `net.js` → `room-ui.js` → `app.js`（全部 `defer`）。精品题后 80 道在 `data-more.js`，首屏后由 `app.js` 异步注入并入（精品层 20 → 100 道）。

## AI 汤主

单人局的 Key 只存在浏览器本地。多人局由房主配置，Key 整包只留在 Durable Object 里，不下发给其他玩家；快照对房主回显地址与「已配 Key」，对其他人只回服务商和模型名。

模型不守 JSON 格式时，会带更强的格式提醒再要一次，并接受以「是。」「不是。」「部分正确。」「与此无关。」开头的明文兜底。本地地址（localhost、内网 IP）从 Cloudflare 机房连不出去，会给出明确提示，而不是笼统的掉线。

2026-09-27 做过一轮判定修复：

- Worker 侧把散落的判定词归一、回复清洗收拢成统一的 `normalizeAskJson`，并与浏览器侧 `guardAnswer` 保持同一口径。
- 思考链出口硬过滤（`REASON_TAIL`）两侧同步补上「但汤底核心…」「汤底的关键是…」这类常见泄漏句式；命中即整段丢弃，只留判定词，绝不把模型的推理原文贴上屏。
- 答案不再被 28 字硬截断，改为按整句保留（浏览器侧）。
- 浏览器侧新增截断检测：`finish_reason=length` 时自动放宽 maxTokens（翻倍，上限 4000）重试，而不是把半截话上屏；Worker 侧对网络抖动 / 5xx 原样重试一次，对格式不可认带提醒再问一次。
- 提示词补了铁律 13——故事内提问即使汤面没提到也应答「不是。」，只有与本题彻底不沾边才允许「与此无关」。
