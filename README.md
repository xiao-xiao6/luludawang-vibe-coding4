## 什么是海龟汤

「海龟汤」是一种水平思考谜题。出题人给出一个看起来离奇的**汤面**，玩家只能提问，一步步还原背后的**汤底**。

汤主只回答三种话：

| 回答 | 含义 |
|:---:|---|
| **是** | 方向对了 |
| **不是** | 方向错了 |
| **与此无关** | 这条线索不在谜题里 |

经典例子：

> **汤面**：男人走进海边的餐厅，点了一碗海龟汤。他只喝了一口，就放下勺子问服务员：「这真的是海龟汤吗？」服务员微笑点头。男人付了钱，回到家中，举枪自尽。为什么？
>
> **汤底**：多年前他遭遇海难，漂流荒岛。同伴把死者的肉煮成汤，骗他那是「海龟汤」。今晚这碗正宗海龟汤味道完全不同，他才明白当年喝下的是什么。

## 怎么玩

1. 从首页开始，或点顶栏的「随机一题」「随机模式」「汤库」。
2. 读汤面，用是非问句提问。问中的线索会留在右侧线索板。
3. 卡住了可以「要提示」，用提示会降星。
4. 想通了点「我要猜汤底」，用自己的话把推理讲清楚。
5. 嫌关键词太死板，点「AI 汤主」，填上自己的模型 Key。配置只存在本机浏览器里。

| 星级 | 条件 |
|:---:|---|
| ★★★ | 0 提示，且提问数不超过该题的标准提问数 |
| ★★☆ | 最多 1 次提示，且提问数不超过标准提问数 + 5 |
| ★☆☆ | 其他情况 |

猜汤底是分层判定：命中核心词直接通关；只摸到关键但没串起来会提示「已经很近了」；把汤面原样复述一遍不会被当成快通关。

## 多人房间

顶栏「多人房间」建房，或用 6 位房号进房。进房后才要昵称。

- 全员点「我准备好了」后自动开局。未准备是红字，已准备是绿字。
- 顺序提问，每人 90 秒。没轮到自己时输入框仍可打字，只是不能发送。
- 轮到自己时画面亮一圈，并有一声短铃。
- 猜汤底随时可以。部分正确冷却 60 秒，完全错误冷却 180 秒，只算在猜的人身上。
- 房间聊天钉在屏幕右下角，默认收成一条。窄屏展开时会抬到提问栏上方，软键盘弹出时先收起。
- 房主可以选汤、随机一题、配 AI 汤主，也可以请离任意玩家。离线超过 1 分钟的座位标成「请离死座位」。
- 问答记录分三处：桌面左侧自动慢滚、中间实时对话、按钮里的完整清单。手机上左侧改为手指可翻，不再锁死滑动。
- 四种回答分色：是（绿）/ 不是（红）/ 与此无关（灰）/ 部分正确（黄）。
- 汤底判定在 Worker 上。单人局可在本机用密码 `081208` 看汤底；多人局同一按钮只在自己屏幕上弹出。

## 双端适配

桌面是三列：问答记录、汤桌、线索板。1180px 以下改成单列，问答记录在上，线索板在下。

| 宽度 | 行为 |
|---|---|
| ≥1181px | 三列。1380px 以下两侧栏略收窄 |
| ≤1180px | 单列。问答记录限高，线索板两列 |
| ≤860px | 线索板改回一列，按钮热区 ≥44px，输入框 16px（避免 iOS 聚焦时放大整页） |
| ≤420px | 顶栏按钮换行，聊天框收成右下一条 |
| ≤360px | 边距和字号再收一档 |

另外照顾到：

- 刘海、手势条用 `viewport-fit=cover` 和安全区内边距。
- 横屏矮视口压缩首页和对话区高度。
- 触屏去掉悬停位移，避免点完按钮还飘着。
- 软键盘弹出时收起音乐台和已展开的房间聊天，并缩短对话区。
- `prefers-reduced-motion` 关掉动效。

## 技术栈

没有前端框架，也没有打包步骤。双击 `index.html` 就能玩单人局。

| 层 | 用了什么 |
|---|---|
| 页面 | 语义化 HTML + 原生 CSS |
| 逻辑 | ES5 风格 IIFE，挂在 `window.SoupXxx` |
| 图形 | Canvas 2D 雨幕 / 闪电 / 粒子 |
| 音频 | Web Audio API 实时合成，无音频文件 |
| 存储 | `localStorage` |
| 离线 | Service Worker（缓存名 `deepsea-soup-v7`）+ Web App Manifest |
| 联机 | Cloudflare Workers + Durable Objects + SQLite |

脚本顺序：`data.js` → `library.public.js` → `engine.js` → `ai.js` → `audio.js` → `fx.js` → `net.js` → `room-ui.js` → `app.js`。精品题后 80 道在 `data-more.js`，首屏后再并入。

## 本地打开

```bash
python -m http.server 8080
```

然后打开 http://localhost:8080 。

`file://` 也能玩单人局，但 Service Worker 和部分浏览器的本地存储会受限。联机需要上面的地址，或 GitHub Pages 线上地址，因为 Worker 只放行这些来源。

## 部署 Worker

先在 `worker/` 目录生成服务端题库（这些文件被 `.gitignore` 挡住，不会进 GitHub）：

```bash
node tools/build_worker_data.js
cd worker
npx wrangler deploy
```

当前账号与 Worker 名写在 `worker/wrangler.toml`：`soup-room`。

允许的前端来源：

- `https://xiao-xiao6.github.io`
- `http://localhost:8080` 与 `http://127.0.0.1:8080`
- `http://localhost:5500`、`4173` 及其 `127.0.0.1` 写法

GitHub Pages 站点本身随 `main` 分支发布，不经过 Wrangler。

## AI 汤主

单人局的 Key 只存在浏览器本地。多人局由房主配置，Key 只留在 Durable Object 里，不下发给其他玩家。

模型不守 JSON 格式时，服务端会再要一次，并接受以「是。」「不是。」「部分正确。」「与此无关。」开头的明文。本地地址（localhost、内网 IP）从 Cloudflare 机房连不出去，会给出明确提示，而不是笼统的掉线。

## 已知限制

- 英文题可以浏览，关键词判定是按中文写的。
- 汤库题材里有不少落在「其他」。
- 内容包含猎奇、犯罪、真实事件向谜题，没有单独的成人开关。
- 同一 isolate 上，同一 IP 每天最多新建 40 间房。
- 手机真机的软键盘高度各不相同，当前用「宽度没变 + 焦点在输入框 + 高度下降超过 140px」来判断。
