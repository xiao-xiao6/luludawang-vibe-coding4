## 什么是海龟汤

「海龟汤」是一种水平思考谜题。出题人给出一个看起来离奇的**汤面**，玩家只能提问，一步步还原背后的**汤底**。

汤主只回答三种话：

| 回答 | 含义 |
|:---:|---|
| **是** | 方向对了 |
| **不是** | 方向错了 |
| **与此无关** | 这条线索不在谜题里 |

经典例子：

> **汤面**：男人走进海边的餐厅，点了一碗海龟汤。他只喝了一口，就放下勺子问服务员：「这真的是海龟汤吗？」服务员微笑点头。男人付了钱，回到家中，举枪自尽。为什么？
>
> **汤底**：多年前他遭遇海难，漂流荒岛。同伴把死者的肉煮成汤，骗他那是「海龟汤」。今晚这碗正宗海龟汤味道完全不同，他才明白当年喝下的是什么。

## 怎么玩

1. 从首页开始，或点顶栏的「随机一题」「随机模式」「汤库」。
2. 读汤面，用是非问句提问。问中的线索会留在右侧线索板。
3. 卡住了可以「要提示」，用提示会降星。
4. 想通了点「我要猜汤底」，用自己的话把推理讲清楚。
5. 嫌关键词太死板，点「AI 汤主」，填上自己的模型 Key。配置只存在本机浏览器里。

| 星级 | 条件 |
|:---:|---|
| ★★★ | 0 提示，且提问数不超过该题的标准提问数 |
| ★★☆ | 最多 1 次提示，且提问数不超过标准提问数 + 5 |
| ★☆☆ | 其他情况 |

猜汤底是分层判定：命中核心词直接通关；只摸到关键但没串起来会提示「已经很近了」；把汤面原样复述一遍不会被当成快通关。

## 多人房间

顶栏「多人房间」建房，或用 6 位房号进房。进房后才要昵称。

- 全员点「我准备好了」后自动开局。未准备是红字，已准备是绿字。
- 顺序提问，每人 90 秒。没轮到自己时输入框仍可打字，只是不能发送。
- 轮到自己时画面亮一圈，并有一声短铃。
- 猜汤底随时可以。部分正确冷却 60 秒，完全错误冷却 180 秒，只算在猜的人身上。
- 房间最多 15 人。
- 房间聊天宽屏时就在右栏，排在「线索板」下面，两块各自固定高度、谁也不挤谁（人数、线索条数、聊天条数怎么变都不动）；聊天多了在日志区内部滚动。1180px 以下右栏折成整行，聊天框改钉屏幕右下角，进房默认展开（点标题可收起）。
- 房主可以选汤、随机一题、配 AI 汤主，也可以请离任意玩家。离线超过 1 分钟的座位标成「请离死座位」。
- 问答记录分三处：桌面左侧自动慢滚、中间实时对话、按钮里的完整清单。手机上左侧改为手指可翻，不再锁死滑动。
- 四种回答分色：是（绿）/ 不是（红）/ 与此无关（灰）/ 部分正确（黄）。
- 汤底判定在 Worker 上。单人局可在本机用密码 `608521` 看汤底；多人局同一把钥匙图标的「密码看汤底（权区）」按钮只在自己屏幕上弹出。
- 每人有私有的「猜底手账」：自己猜过的每一条内容和判定，别人看不到（每人上限 60 条）。
- 结算和进行中都有战况三小格：个人提问数 / 全桌总提问数 / 从开锅算起的用时。
- 汤库与房间「选一锅汤」的卡片都带题材标签（脑洞 / 悬疑 / 都市 …）；卡片右上角的绿勾是本机「已熬出汤底」标记，点一下切换，熬出汤底时自动打勾，只存在自己浏览器里。
- 界面全部图形为同一套手绘线条 SVG 图标（`js/icons.js`），不再使用 emoji。

联机服务：https://soup-room.57gqq9hsq.workers.dev

## 双端适配

桌面是三列：问答记录、汤桌、右栏（上线索板 + 下房间聊天）。1180px 以下改成单列，问答记录在上，线索板在下（聊天框回到右下角悬浮）。

| 宽度 | 行为 |
|---|---|
| ≥1181px | 三列。1380px 以下两侧栏略收窄。多人房时右栏是「上线索板 + 下房间聊天」，两块各自固定高度 |
| ≤1180px | 单列。问答记录限高，线索板两列。房间聊天恢复右下角悬浮（fixed） |
| ≤860px | 线索板改回一列，按钮热区 ≥44px，输入框 16px（避免 iOS 聚焦时放大整页） |
| ≤420px | 顶栏按钮换行，聊天框收成右下一条 |
| ≤360px | 边距和字号再收一档 |

另外照顾到：

- 刘海、手势条用 `viewport-fit=cover` 和安全区内边距。
- 横屏矮视口压缩首页和对话区高度。
- 触屏去掉悬停位移，避免点完按钮还飘着。
- 软键盘弹出时收起音乐台和已展开的房间聊天，并缩短对话区。
- `prefers-reduced-motion` 关掉动效。

### 手机端省电档（`@media (pointer: coarse)` + `SoupFx` 内 LITE）

针对「120Hz ProMotion 手机上不开特效都发烫、开特效卡」的反馈（iPhone 16 Pro）。根因是所有无限循环动画和 rAF 在 120Hz 下按 120 次/秒计费，而 `text-shadow` / `box-shadow` / `filter` / `background-position` 这几类关键帧没法走 GPU 合成，等于常驻重画整块内容。触屏设备一律：

| 开销 | 桌面 | 手机端 |
|---|---|---|
| 雨幕 Canvas | 60~120fps、dpr≤2、220 丝每丝一次 stroke | 封顶 30fps、dpr≤1.5、密度 ×0.6、按透明度分桶每桶一次 stroke |
| 蒸汽 / 扫描线 / 全屏 backdrop-filter | 开 | 关（overlay 混合与高斯模糊是 iOS 烧 GPU 大户） |
| 标题辉光 / 徽章呼吸 / 结算炫彩字 / 报喜彩框 / 墨晕 | 无限循环 | 全部停成静态一档 |
| 问答记录自动慢滚 | rAF 每帧写 scrollTop | 节流到约 30fps 才写一次 |
| 庆祝烟花 | 全量粒子 | 粒子减半 |
| 氛围特效开关 | 默认开 | 新访客默认关（存过的偏好不动） |

桌面 `pointer: fine` 完全不受影响；`SoupFx.stats()` 会回显 `lite` 方便真机排查。

## 技术栈

没有前端框架，也没有打包步骤。双击 `index.html` 就能玩单人局。唯一引入的第三方库是本地化的 GSAP（`assets/vendor/gsap.min.js`），只用于转场，缺了也能降级运行。

| 层 | 用了什么 |
|---|---|
| 页面 | 语义化 HTML + 原生 CSS |
| 逻辑 | ES5 风格 IIFE，挂在 `window.SoupXxx` |
| 转场 | GSAP 黑幕三段式（盖黑 → 换内容 → 拉开），无 GSAP 时回退 Web Animations / CSS |
| 图标 | 一套 24×24 手绘线条 SVG（`js/icons.js`），stroke=currentColor，全站零 emoji |
| 图形 | Canvas 2D 雨幕 / 闪电 / 粒子 |
| 音频 | Web Audio API 实时合成，无音频文件 |
| 字体 | 标题用子集化 `NotoSerifSC-title.woff2` |
| 存储 | `localStorage` |
| 离线 | Service Worker（缓存名 `deepsea-soup-v17`）+ Web App Manifest |
| 联机 | Cloudflare Workers + Durable Objects + SQLite |

脚本顺序：`gsap.min.js` → `data.js` → `library.public.js` → `engine.js` → `ai.js` → `audio.js` → `fx.js` → `transition.js` → `icons.js` → `net.js` → `room-ui.js` → `app.js`（全部 `defer`）。精品题后 80 道在 `data-more.js`，首屏后再异步并入。`transition.js` 负责黑幕转场，没有 GSAP 时自动退回 Web Animations / CSS 过渡。

## 本地打开

```bash
python -m http.server 8080
```

然后打开 http://localhost:8080 。

`file://` 也能玩单人局，但 Service Worker 和部分浏览器的本地存储会受限。联机需要上面的地址，或 GitHub Pages 线上地址，因为 Worker 只放行这些来源。

## 部署 Worker

先在 `worker/` 目录生成服务端题库（这些文件被 `.gitignore` 挡住，不会进 GitHub）：

```bash
node tools/build_worker_data.js
cd worker
npx wrangler deploy
```

当前账号与 Worker 名写在 `worker/wrangler.toml`：`soup-room`。

允许的前端来源：

- `https://xiao-xiao6.github.io`
- `http://localhost:8080` 与 `http://127.0.0.1:8080`

## AI 汤主

单人局的 Key 只存在浏览器本地。多人局由房主配置，Key 只留在 Durable Object 里，不下发给其他玩家。

模型不守 JSON 格式时，服务端会再要一次，并接受以「是。」「不是。」「部分正确。」「与此无关。」开头的明文。本地地址（localhost、内网 IP）从 Cloudflare 机房连不出去，会给出明确提示，而不是笼统的掉线。

2026-09-27 做过一轮判定修复：Worker 侧把散落的判定词归一、回复清洗收拢成统一的 `normalizeAskJson`，并与浏览器侧 `guardAnswer` 保持同一口径；思考链出口硬过滤（`REASON_TAIL`）两侧同步补上「但汤底核心…」「汤底的关键是…」这类常见泄漏句式；答案不再被 28 字硬截断，改为按整句保留；模型回复被 `maxTokens` 掐断时会识别 `finish_reason=length`，自动放宽额度（翻倍、上限 4000）重试而不是把半截话上屏；提示词补了铁律 13——故事内提问即使汤面没提到也应答「不是。」，只有与本题彻底不沾边才允许「与此无关」。

## 已知限制

- 外文题已全部译成中文（繁译简 436 / 英译中 297 / 日译中 165），判定按中文写。其中 2 道题保留原文符号（《熵增》的数字串、《给三兄弟的一封信》的化学式），是题面本身如此，不是漏翻。
- 翻译题的汤底部分出自机器翻译，措辞可能生硬；这类题没有关键词表，只能靠 AI 汤主判定。
- 日译中里约十条刻意保留少量日文假名：颜文字、日语双关谜面（`たな？`、`ふなよい＝2741`）、五十音图题——去掉梗就没了。
- 汤库题材标签有 941 道落在「其他」，长尾分类没做完。
- 内容包含猎奇、犯罪、真实事件向谜题，没有单独的成人开关。
- 同一 isolate 上，同一 IP 每天最多新建 40 间房。
- 手机真机的软键盘高度各不相同，当前用「宽度没变 + 焦点在输入框 + 高度下降超过 140px」来判断。
