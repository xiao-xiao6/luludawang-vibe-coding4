## 🐢 什么是海龟汤

「海龟汤」是一种**水平思考谜题**：出题人给出一个看起来离奇、甚至违背常理的**汤面**（谜面），
玩家只能通过提问来还原背后那个合理的**汤底**（真相）。

出题人（这里叫**汤主**）只会回答三种话：

| 回答 | 含义 |
|:---:|---|
| **是** | 你的猜测方向正确 |
| **不是** | 方向错误，换个角度 |
| **与此无关** | 这条线索不在谜题里 |

经典例子：

> **汤面**：男人走进海边的餐厅，点了一碗海龟汤。他只喝了一口，就放下勺子问服务员：「这真的是海龟汤吗？」服务员微笑点头。男人付了钱，回到家中，举枪自尽。为什么？
>
> **汤底**：多年前他遭遇海难，漂流荒岛，饿到极限时，同伴把死者的肉煮成汤，骗他那是「海龟汤」。今晚这碗正宗海龟汤的味道完全不同——他瞬间明白当年喝下的是什么。他无法承受这份真相。

这个项目的目标，是把这种「一句一句逼近真相」的体验，做成一个**打开就能玩、手机也能玩、关掉网络还能玩**的网页小游戏。

## 🎮 怎么玩

1. **挑一锅汤** —— 从汤单里选，或点「随机一题」「🎲 随机模式」「📅 今日汤」。
2. **读汤面** —— 汤面会逐字打出，营造「刚端上来」的感觉。
3. **提问** —— 在输入框里问「他认识死者吗？」这类**是非问句**，汤主回答「是 / 不是 / 与此无关」。
   - 问中一条线索，它会**自动留在右侧线索板**上。
   - 线索板上没出现的角度，说明还没问到。
4. **卡住了？** —— 点「要提示」，按难度给 2~4 级提示（用提示会降星）。
5. **想通了** —— 点「我要猜汤底」，用自己的话把推理讲清楚（不用复述原文）。
6. **揭晓** —— 汤主判断你是否真的熬到汤底，给出星级与完整汤底。

### 评级规则

| 星级 | 条件 |
|:---:|---|
| ★★★ | 0 提示 且 提问数 ≤ `par` |
| ★★☆ | ≤1 提示 且 提问数 ≤ `par + 5` |
| ★☆☆ | 其他情况 |

> `par` 是每道题的「标准提问数」，取值 6~10，按题目复杂度手调。

### 判定逻辑

猜汤底不是简单的字符串匹配，而是**分层判定**：

- **命中核心词**（`coreKeywords`）→ 直接通关
- **命中足够多真相词**（`truthKeywords`）→ 通关
- **只摸到关键但没串起来** → 「已经很近了」
- **把汤面原样复述一遍** → 明确点破：「汤主要的是你没说出口的那一层」（防止玩家误以为快到了）
- **太短且零命中** → 提示把「谁、为什么、怎么做的」串成完整一句

## 📊 两套数据集

项目刻意把**手工精品**和**爬取汤库**做成两层**完全隔离**的数据，互不污染：

| 层 | 变量 | 条数 | 玩法 | 校验 |
|---|---|---:|---|---|
| **精品层** | `PUZZLES` | **100** | 关键词汤主 + AI 汤主，全功能 | `smoke_test.js` 9791 项 |
| **库层** | `SOUP_LIBRARY` | **1361** | 浏览 / 搜索 / 筛选；仅 AI 汤主可对战 | `library_test.js` 68 项 |

**为什么要隔离**：精品层每道题都被硬断言约束（`clues >= 6`、`truthKeywords >= 8`、
`coreKeywords ⊆ truthKeywords`、每条线索有独占关键词……），而爬取来的汤库数据**根本没有这些字段**。
混进同一个数组，自检立刻挂。所以：

- 存档 key 分开：`deepsea_soup_v1`（精品）vs `deepsea_soup_library_v1`（汤库）
- 题材词表分开：18 个项目受控词 vs 27 个库受控词
- 库层成绩**绝不写进**精品层存档

## 🛠 技术栈

**没有框架，没有构建，没有依赖。** 全部是浏览器原生能力：

| 层 | 用了什么 |
|---|---|
| 结构 | 语义化 HTML5 |
| 样式 | 原生 CSS（自定义属性做主题、Grid/Flex 布局、`prefers-reduced-motion` 降级） |
| 逻辑 | 原生 ES5 风格 JavaScript（IIFE 模块化，`root.SoupXxx` 挂全局） |
| 图形 | Canvas 2D（雨幕 / 闪电 / 粒子）+ CSS 动画（雾气 / 扫描线 / 抖屏） |
| 音频 | **Web Audio API 实时合成**（无音频文件，四首曲子全靠振荡器 + 噪声 + 包络生成） |
| 存储 | `localStorage` |
| 离线 | Service Worker + Web App Manifest |
| AI | `fetch` 直连 OpenAI 兼容 / Anthropic 接口 |

> 💡 **音乐为什么不用音频文件**：四首曲子加起来如果放 MP3，至少几百 KB。
> 改成实时合成后，体积是 0，还能随场景无缝淡入淡出、任意延长，代价只是首次合成几百毫秒。

### 脚本加载顺序

```html
<script src="js/data.js"         defer></script>  <!-- 精品题库（前 20 题核心分片） -->
<script src="js/library.public.js" defer></script>  <!-- 汤库 1361 条（含汤底，明文公开） -->
<script src="js/engine.js"       defer></script>  <!-- 判定引擎 -->
<script src="js/ai.js"           defer></script>  <!-- AI 汤主 -->
<script src="js/audio.js"        defer></script>  <!-- 程序化音乐 -->
<script src="js/fx.js"           defer></script>  <!-- 特效引擎 -->
<script src="js/app.js"          defer></script>  <!-- 主逻辑 -->
```

**首屏性能优化**：100 道题的完整数据约 219 KB，会拖慢首屏。所以拆成两片——
`data.js` 只带前 20 题（约 49 KB），剩下 80 题在 `data-more.js`（约 169 KB）里，等首屏渲染完成后异步并入同一个
`PUZZLES` 数组。计数分母用 `PUZZLES_TOTAL`，所以数字不会从「/20」跳到「/100」。

### 可选的本地 CORS 桥

部分 AI 服务商不允许浏览器跨域直连。如果你要用这类服务商（例如 TokenRhythm），
需要一个**只在本机运行**的转发桥（属于开发工具，放在站点目录之外）：

```
_soup-dev/game-dev/proxy/      # 开发用，不随站点发布
├── proxy.js                   # 白名单头模式，只监听 127.0.0.1:8787
├── start-proxy.bat            # 前台启动
├── start-proxy-hidden.vbs     # 隐藏窗口启动
└── bridge.log                 # 运行日志（启动/占端口/转发异常）
```

原理：转发时用**请求头白名单**——只带认证与内容协商真正需要的头，
浏览器专有指纹头（`Origin`、`Referer`、`Sec-Fetch-*`、`Sec-Ch-Ua-*`）全部不转发，
从而避开上游的 Origin / CSRF 校验。API Key 只在本机与上游之间传递，不经过任何第三方。

## 🚀 快速开始

### 直接玩

```bash
# 方式一：双击 index.html（file:// 直开，功能完整）
# 方式二：起个静态服务器（推荐，Service Worker 需要 http/https）
python -m http.server 8080
# 然后访问 http://localhost:8080
```

> Service Worker 只在 `https:` 或 `localhost` 下注册；`file://` 打开时功能正常，只是没有离线缓存。

### 重新生成汤库数据

```bash
cd 海龟汤小游戏

# 需要数据源：../海龟汤汤面大全/海龟汤汤面大全.jsonl
python tools/import_soup_library.py           # 生成 data/Library/soups.json 与 data/Library/library.data.js
python tools/import_soup_library.py --check   # 校验幂等，期望无 diff、exit 0

# 重建三份产物：服务端题库（含汤底）+ 前端公开档（含汤底，明文发布）
node tools/build_worker_data.js               # worker/src/*.data.js + js/library.public.js
node tools/build_worker_data.js --check       # 幂等自检
```

导入器是**字节级幂等**的：禁用 CRLF、禁用 BOM、字典序排序、不写当天日期。
连跑两次 `sha256` 完全一致。

## 🤖 AI 汤主

默认的「关键词汤主」是确定性的：撞到关键词就回答，快但死板，换个说法就听不懂。

**AI 汤主**把每道题的**汤面 + 汤底**一起交给大模型，让它真正理解你的自然语言提问。

### 内置 9 家服务商

| 服务商 | 默认模型 | 备注 |
|---|---|---|
| DeepSeek | `deepseek-chat` | 国内直连、便宜 |
| Moonshot / Kimi | `moonshot-v1-8k` | 长上下文 |
| 通义千问 | `qwen-plus` | 阿里云百炼兼容模式 |
| 智谱 GLM | `glm-4-flash` | flash 档免费额度够玩 |
| 硅基流动 | `Qwen/Qwen2.5-7B-Instruct` | 聚合站，模型名要写全 |
| OpenAI | `gpt-4o-mini` | 官方接口对浏览器直连不友好，建议自建代理 |
| Anthropic Claude | `claude-3-5-haiku-latest` | 已带上浏览器直连所需请求头 |

### 防剧透设计

- 系统提示词里明确要求：**永远不能把汤底直接说出来**，只能回答「是 / 不是 / 与此无关」
- 对**没有预设线索清单**的题（汤库题），提示词会输出「本题没有预设线索清单，永远不要把 clue 置为非 0」
- 空 `truth` 的题会早返回，绝不误拦
- 汤库中 `mode: "surface"` 的题（无汤底）直接禁用 AI 入口，不浪费你的 token

### 隐私

API Key **只存在你自己的浏览器 `localStorage` 里**（key: `deepsea_soup_ai_v1`），
请求由浏览器直连服务商，不经过任何第三方服务器。

> 部分服务商不允许浏览器跨域直连（CORS）。开发区 `_soup-dev/game-dev/proxy/` 里附带一个本地 CORS 桥，
> 只监听 `127.0.0.1`，转发时用**请求头白名单**避开上游的 Origin 校验，Key 只在本机与上游之间传递。

### 清洗流水线（顺序不可换）

```
① 读 JSONL                    → 1397
② 剔除垃圾（正文含代码片段）   → -13
③ 去重（normalize(surface)）  → -16（合并）
④ 排除与现有 100 题重叠（标题）→ -7
⑤ 净增                        → 1361
```

垃圾判定规则写进解析器（不硬编码序号）：正文里出现 `${`、`<script`、`console.log`、
`getElementById` 等代码片段的条目直接丢弃。

### 幂等保障

```python
open(path, "w", encoding="utf-8", newline="\n")   # 禁 CRLF、禁 BOM
json.dumps(obj, ensure_ascii=False, sort_keys=True, indent=2)
```

- `id` / `rawTags` / `cats` / 输出顺序全部确定性排序
- **禁止写入 `importedAt`**：它是当天日期，跨天重跑必产生 diff，`--check` 会永远失败

### ID 设计：内容哈希而非下标

```js
id: "lib_" + sha1(normalize(surface)).slice(0, 12)
```

数组下标方案在数据源增删后会整体错位，玩家存档全废。内容哈希天然幂等，还顺便实现了去重。
代价是「改一个错字 → id 变 → 该题进度丢」——对浏览型汤库可以接受。

## 🧠 设计取舍

一些刻意的决定，以及为什么：

| 决定 | 原因 |
|---|---|
| **零构建、零依赖** | 一个 `index.html` 就能跑，方便分享、Fork、离线。代价是手动管理脚本加载顺序 |
| **ES5 风格 IIFE** | 不引入转译步骤，兼容老设备；模块边界靠 `root.SoupXxx` 显式挂载 |
| **题库拆两片** | 219 KB → 49 KB 首屏。异步并入同一数组，对上层逻辑完全透明 |
| **音乐实时合成** | 0 体积、可任意延长、可无缝淡入淡出。代价是首次合成有几百毫秒延迟 |
| **两层数据集隔离** | 手工精品的质量约束（每线索独占关键词等）爬取数据满足不了，混一起必然污染 |
| **汤库 ID 用内容哈希** | 幂等 + 去重，避免数组下标错位导致存档全废 |
| **打雷抖动可关闭** | 抖屏对部分用户是真实的不适来源（前庭敏感），所以做成开关而非硬编码 |
| **今日汤用固定东八区** | 而不是设备本地时间——否则切时区会突然换题 |
| **猜底判定要识别「复述」** | 否则玩家把汤面念一遍就得到「快到了」，产生虚假进度感 |
